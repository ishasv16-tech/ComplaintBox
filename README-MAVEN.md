HOSTELHUB + SPRING BOOT
1. Open this folder in IntelliJ as a Maven project.
2. Set MySQL password in src/main/resources/application.properties.
3. Run com.complaintbox.ComplaintBoxApplication.
4. Maven builds the original React/Vite HostelHub frontend into Spring Boot static resources automatically.
5. Browser: http://localhost:8080
